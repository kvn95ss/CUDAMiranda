# CUDAMiranda
An update to make CUDAMiranda compatible with current version of CUDA

# Why
The idea of optimizing GPU-based tasks have become relevant with wide-spread adoption of GPUs capable to handling machine learning and AI based tasks. Several tools exist in literature, some broken while others are seeing more adoption.

# How
I have used LLM (Mainly Claude Code) to ensure the core algorithm is not altered, but it becomes compatible with a more recent version of CUDA.
